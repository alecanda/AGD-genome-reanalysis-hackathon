Reanalysis triage — scoring report

Synthetic data, generated for a hackathon exercise. Not clinical evidence. Weights below are judgment calls, not derived from outcomes data.

How this score is built

Every non-solved case gets a final_score computed as:

final_score = (Tier A + Tier B + Tier C + age tiebreaker) × case_status_multiplier

solved cases are excluded from ranking entirely, not scored low.

Tier C — free-text note classification

The note field is matched (case-insensitive substring) against fixed phrase lists. If several signal phrases match, the highest-scoring one wins — points are not summed.

Administrative / no-signal phrases (0 points): routine, annual review, internal cohort, reviewed at mdt, part of research cohort, external referral, referred from clinical genetics, referred from paediatric neurology, no family history reported, prenatal history unremarkable, sample received from external lab, consanguineous family.

Notes matching neither list are flagged unclassified_note for manual review rather than silently scored 0.

Tiebreaker — time since last analysis

0.5 points per year since last_analysis, capped at 5 points. Small on purpose — it only matters among otherwise-similar scores.

Missing data

No case is dropped for having NA values. Any scoring-relevant field that was NA is treated as 0 for that component and listed in data_completeness_flags so a reviewer can see which scores rest on incomplete data.
