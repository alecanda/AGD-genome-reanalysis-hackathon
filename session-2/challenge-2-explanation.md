# Challenge 2 — Why is this candidate interesting?

Build a candidate-explanation component for a Talos result.

Minimum concept:

    Gene / variant
    Rank or position
    Inheritance/reason
    Talos evidence
    Phenotype evidence if available
    Supporting evidence
    Warnings / limitations
    Links to source evidence

You may implement this deterministically from Talos data, use an LLM to generate prose, or combine both.

**Strong solution:** every claim can be traced back to source data. Avoid unsupported clinical conclusions.
