# Session 1 — Individual onboarding (16:15–16:45)

Goal: a quick, low-stakes first experience of using Claude on a real bioinformatics chore, before teaming up.

Participants pick one:
- [Track A — Tidy the data](track_a_tidy_data/) — clean/reshape a messy variant candidate spreadsheet
- [Track B — Reskin the report](track_b_reskin_report/) — restructure/restyle an HTML variant report

Both use the same [agentic workflow cheat sheet](../docs/claude_agentic_workflow_cheatsheet.md) — hand this out at the very start.

16:45–17:00: facilitator-led Q&A on what people ran into (good moment to surface common friction points before the group session).
